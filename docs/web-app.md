# 🖥 Веб-приложение

**Адрес:** https://ravshanbekrakhmetullayev-ui.github.io/java-calculator/

Калькулятор и пульт тестирования в одном окне. Сейчас главная функция — калькулятор, а всё вокруг него — интеграции, которые его проверяют. Когда продукт сменится, карта и станции останутся, поменяется только левая часть.

## Установить как отдельное приложение

Калькулятор ставится на компьютер как обычная программа: своя иконка в Dock и Launchpad, своё окно без адресной строки, работает без интернета (данные интеграций обновятся, когда появится сеть).

| Где | Как |
|---|---|
| Chrome, Edge, Яндекс Браузер | Кнопка **Установить приложение** справа вверху → **Установить** |
| Safari на Mac (macOS 14+) | **Файл → Добавить в Dock** |
| iPhone, iPad | **Поделиться → На экран «Домой»** |
| Android | **⋮ → Установить приложение** |

## Что на экране

| Часть | Что делает |
|---|---|
| **Шапка** | Состояние проекта: последняя сборка, сколько тестов прошло, Quality Gate, какая версия сайта опубликована. Нажатие открывает нужную станцию |
| **Калькулятор** | Тот же движок, что в Java-версии: точная арифметика (0.1 + 0.2 = 0.3), скобки, √, x², %, 1/x, ±, память MC/MR/M+/M−, история, кэш |
| **Карта интеграций** | Станции — сервисы, линии — пути данных между ними. Пунктир — обратная связь в Jira. Точка на станции: зелёная — всё хорошо, жёлтая — выполняется, красная — нужно внимание |
| **Маршрут** | Открывается по нажатию на станцию (см. ниже) |
| **Настройки** | Шестерёнка справа вверху или клавиша `S` |

## Маршрут: «откуда → что → куда дальше»

Нажмите на любую станцию — откроется экран выбора, как в игре:

- **Приходит из** (слева) — станции, которые передают сюда данные, и что именно они передают. Нажатие переносит на ту станцию.
- **Станция** (в центре) — что она делает, её живые цифры и главные действия.
- **Куда дальше** (справа) — пронумерованные пути. Выбрать можно мышью или клавишами `1`–`9`. Пути со стрелкой ↗ открывают внешний сайт.

Сверху — пройденный маршрут: можно вернуться на любой шаг. `⌫` — шаг назад, `Esc` — к карте.

| Станция | Данные | Действия |
|---|---|---|
| Jira | Задачи и статусы*, коммиты с ключами CALC-N | Открыть доску, создать задачу или баг с заполненными полями |
| GitHub | Ветка, последний push, коммиты, открытые PR | Открыть репозиторий, pull requests |
| GitHub Actions | Последние запуски со статусами | **Запустить конвейер** и следить за шагами в реальном времени |
| SonarCloud | Quality Gate, баги, уязвимости, code smells, рейтинги A–E, главные замечания | Открыть замечание, создать по нему задачу в Jira |
| Jenkins | Этапы из Jenkinsfile | Открыть сервер (когда указан адрес) |
| Автотесты | Итог последнего прогона в CI, покрытие JaCoCo | **Запустить в браузере** или **в CI**. На упавший тест — кнопка «баг в Jira» |
| Allure | Сколько тестов прошло, упало, сломано; история прогонов | Открыть отчёт, завести баг |
| Калькулятор | История, кэш, память | Вернуться к калькулятору |
| Тест-кейсы | 34 кейса по разделам, сколько автоматизировано | Открыть кейсы, CSV для TMS |

\* Список задач Jira появляется после настройки секретов — см. ниже.

## Запуск автотестов

**В браузере.** Станция «Автотесты» → «В браузере — сейчас». Прогоняются 104 теста JavaScript-движка за доли секунды:
- 78 сценариев «нажатия → экран» — их генерирует `tools/extract_cases.py` прямо из Java-тестов, поэтому обе версии проверяются одинаково;
- 26 проверок памяти, кэша, истории, формата чисел и вставки из буфера.

**В CI.** Станция «Автотесты» → «В CI» (или станция GitHub Actions → «Запустить конвейер»). Запускается полный конвейер: 114 Java-тестов, 104 веб-теста, покрытие, SonarCloud, новый отчёт Allure и публикация сайта. Ход выполнения виден прямо в приложении.

Для запуска из приложения нужен токен GitHub (один раз):

1. Откройте https://github.com/settings/personal-access-tokens/new
2. **Token name:** `qa-hub`. **Expiration:** на ваш выбор.
3. **Repository access → Only select repositories →** `java-calculator`.
4. **Permissions → Repository permissions:**
   - **Actions** → `Read and write`;
   - **Contents** → `Read-only`.
5. **Generate token** → скопируйте токен (`github_pat_…`).
6. В приложении: шестерёнка → **Токен GitHub для запуска конвейера** → вставьте → **Сохранить**.
7. **Проверить подключения** — строка «Запуск конвейера» должна стать зелёной.

Токен хранится только в вашем браузере (localStorage) и уходит только на api.github.com. В файл настроек при скачивании он не попадает.

## Данные Jira (по желанию)

Браузер не может читать Jira с другого сайта — так защищён Atlassian. Поэтому список задач получает конвейер и кладёт его в `data/jira.json`:

1. Создайте API-токен: https://id.atlassian.com/manage-profile/security/api-tokens
2. В репозитории: **Settings → Secrets and variables → Actions** → добавьте `JIRA_EMAIL` (ваша почта в Jira) и `JIRA_API_TOKEN`.
3. Запустите конвейер. Задачи появятся на станции Jira.

Создавать задачи и баги можно и без этого: кнопки открывают форму Jira с уже заполненными полями.

## Как устроено

```
web/
├── index.html            разметка
├── css/app.css           оформление
├── js/engine.js          движок калькулятора (точная десятичная арифметика на BigInt)
├── js/suite.js           набор автотестов — один для браузера и для Node
├── js/integrations.js    GitHub, SonarCloud, Allure, Jira, настройки
├── js/stations.js        станции, линии карты и содержимое каждой станции
├── js/app.js             интерфейс: калькулятор, карта, маршрут, настройки
└── tests/
    ├── cases.json        сценарии из Java-тестов (генерируется)
    └── run-node.mjs      запуск веб-тестов в CI с результатами для Allure
tools/
├── extract_cases.py      Java-тесты → web/tests/cases.json
└── build_site_data.py    данные сайта: сборка, тест-кейсы, Jenkins, Jira, покрытие
```

На GitHub Pages конвейер публикует:

| Путь | Что |
|---|---|
| `/` | Веб-приложение |
| `/allure/` | Отчёт Allure (с историей прогонов) |
| `/coverage/` | Отчёт JaCoCo о покрытии |
| `/data/*.json` | Данные для станций |

## Запуск на своём компьютере

```bash
cd ~/Documents/calculator/java-calculator
python3 tools/build_site_data.py web    # данные для станций (по желанию)
cd web && python3 -m http.server 8000
```

Откройте http://localhost:8000. Отчёт Allure локально не собирается — в настройках укажите адрес `https://ravshanbekrakhmetullayev-ui.github.io/java-calculator/allure/`.

Веб-тесты в терминале: `node web/tests/run-node.mjs`.

## Как добавить новую функцию

1. **Новая станция** — запись в `STATIONS` и линии в `EDGES` (`web/js/stations.js`), функция в `RENDER` с содержимым. Карта и экран маршрута подхватят её сами.
2. **Новый продукт вместо калькулятора** — замените `engine.js` и блок `.calc` в `index.html`. Карта, станции и конвейер останутся.
3. **Новые веб-тесты** — добавьте сценарий в Java-тест (он попадёт в `cases.json`) или ручной тест в `extraTests()` в `suite.js`.
